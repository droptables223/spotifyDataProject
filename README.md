# spotifyDataProject
GUI is contained in the SpotifyThings folder

Libraries used:
* Flask
* Jinja2
* PyMongo
* scikit-learn
* Ajax

in cmd/powershell run python app.py
wait for restart then use local host to view GUI


## Explanation of ` .ipynb ` files

| File | Purpose |
| --- | --- |
| databaseProject | central tendencies of data, data visualization, correlation analysis |
| spotifyDatabase | data cleaning, database injection, data model training, sample queries, genre prediction and song recommendation functions |
